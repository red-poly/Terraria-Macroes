# Terraria-Macroes
This repo contains various Terraria macroes I make to make my (and hopefully your) life easier.
*All of these are very simple and can be run out of any Python interpreter/IDE and require minimal coding knowledge to understand.*

## Requirements 
The current macroes here require:
- pyautogui
- keyboard

How to install both of these:
```pip install pyautogui keyboard```
